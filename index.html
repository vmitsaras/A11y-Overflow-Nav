A11y Overflow Nav

Resize the component rather than the browser. Switch layout mode, direction, label length, and text scale while inspecting the exact visible/overflow distribution and lifecycle events.

View GitHub repository

Initialization and lifecycle

Author every destination in the primary list and keep the final More control hidden. Register lifecycle listeners before initialization so the synchronous initial events are captured.

Semantic structure

<nav data-a11y-overflow-nav aria-label="Primary">
  <ul data-overflow-nav-list>
    <li data-overflow-nav-item><a href="/articles">Articles</a></li>
    <li data-overflow-nav-control hidden>
      <div data-overflow-nav-menu>
        <button aria-controls="overflow-panel">More</button>
        <div id="overflow-panel" hidden>
          <ul data-overflow-nav-overflow-list></ul>
        </div>
      </div>
    </li>
  </ul>
</nav>

Initialize and observe

import {
  createOverflowNav,
  OVERFLOW_NAV_EVENTS,
} from 'a11y-overflow-nav';

const root = document.querySelector('[data-a11y-overflow-nav]');

if (root instanceof HTMLElement) {
  for (const name of Object.values(OVERFLOW_NAV_EVENTS)) {
    root.addEventListener(name, (event) => {
      console.log(event.type, event.detail.reason, event.detail.overflowCount);
    });
  }

  const instance = createOverflowNav(root, {
    observeResize: true,
    fitTolerance: 1,
    menuButtonOptions: {},
  });

  instance.refresh(); // After application-driven content changes.
  // instance.destroy(); // During application teardown.
}

An initial redistribution can emit overflow-nav:change before overflow-nav:init. A refresh can likewise emit a change before its refresh event. Destroy emits its snapshot before the authored DOM and state are restored.
