Basic example

Navigation that adapts without losing its order

A Priority+ navigation keeps the links that fit visible and moves the remaining original links into an accessible More menu.

Scenario

A publication has more destinations than every layout can display on one line. Readers should still reach every destination in the same source order at narrow widths or when text is enlarged.

Try it

  • Use Narrow preview or resize the window and watch links move into or out of More.
  • Use Tab to reach the visible links and the More button.
  • Open More with Enter or Space, then use arrow keys and Escape.
  • Increase browser text size and confirm every link stays available.

    Use the plugin

    Import createOverflowNav(), find the navigation root, and initialize it after the markup is available.

    import { createOverflowNav } from 'a11y-overflow-nav';

const root = document.querySelector('[data-a11y-overflow-nav]');

if (root instanceof HTMLElement) {
  createOverflowNav(root);
}

    Accessibility notes

    • The navigation remains a named landmark containing real links and a real button.
    • Without JavaScript, all destinations remain visible and More stays hidden.
    • The plugin moves original list items, preserving source order and link identity.
    • Focus is preserved when responsive redistribution moves the active destination.
    • The demo uses no motion; reduced-motion preferences remain respected.
    • Nested and mega-menu navigation are intentionally outside this plugin’s scope.

    Developer notes

    Initialize [data-a11y-overflow-nav] with createOverflowNav(). The child elements use the documented data-* selectors. This package ships no layout CSS; the local styles.css belongs only to this demo. Default options are used.
